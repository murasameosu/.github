<h1 align="center">murasame! — osu! Private Server</h1>

<p align="center"><strong>murasame!</strong> is an all-new, invite-only osu! private server designed for both fun and community.</p>


## Features of This Server

- Enjoy all **osu!supporter** features for free  
  (osu!direct, friend rankings, and more)
- It is compatible with the **osu!lazer client**!
- Change your username **any time**  
- Earn **pp on Loved beatmaps** *(Vanilla only)*  
- **Relax and AutoPilot uses the same PP system as Vanilla**  
- **Dans available for all modes**  
- More unique features are in the works!

## Want to Join?

Get an invitation code from a friend who has already joined the server and hop in!  
If you are lucky, you might even get one from the developers!
